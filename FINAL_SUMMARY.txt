     ├─ config              Cambiar message_threshold, levenshtein_threshold
     ├─ status              Ver configuración actual

     ├─ config              Cambiar channel_threshold, role_threshold

     ├─ /config             Ver configuración completa
     ├─ /help               Ver ayuda
     └─ /setup-alerts       Configurar canales de alertas

🔄 FLUJO DE COMANDO
───────────────────────────────────────────────────────────────────────────────

Usuario escribe /anti-raid config
           ↓
CommandHandler carga el comando
           ↓
Verifica permisos (Manage Guild)
           ↓
Valida parámetros
           ↓
Ejecuta lógica
           ↓
Actualiza StateManager
           ↓
Crea Embed con respuesta
           ↓
Envía mensaje a Discord
           ↓
Usuario ve respuesta formateada

───────────────────────────────────────────────────────────────────────────────
🆘 SOPORTE
───────────────────────────────────────────────────────────────────────────────

Si algo no funciona:
  1. Revisar logs en consola
  2. Ver /config para verificar valores
  3. Leer COMMANDS_GUIDE.md
  4. Leer SETUP_CHECKLIST.md
  5. Revisar ARCHITECTURE.md

Problemas comunes:
  ❌ "Comando no encontrado"
     → Esperar 1 hora o usar DEV_GUILD_IDS
  
  ❌ "No tienes permisos"
     → Verificar rol "Manage Server"
  
  ❌ Bot offline
     → Verificar TOKEN en .env
  
  ❌ Comandos no responden
     → Verificar intents en index.ts
