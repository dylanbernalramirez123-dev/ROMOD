│                                                                          │
│  Subcomando: status                                                     │
│  └─ Muestra: Estado, valores actuales, canal de alertas                │
│                                                                          │
│  Subcomando: quarantine                                                 │
│  ├─ action: list     | Ver cuentas en cuarentena                       │
│  └─ action: remove   | Remover usuario de cuarentena                   │
│                                                                          │
│  📝 Ejemplo:                                                             │
│     /anti-raid config setting:join_rate_limit value:10                │
│     /anti-raid status                                                   │
│     /anti-raid quarantine action:list                                  │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 🛑 ANTI-SPAM (/anti-spam)                                               │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  Subcomando: config                                                     │
│  ├─ setting: message_threshold       | Número de mensajes para spam    │
│  ├─ setting: spam_window             | Ventana en milisegundos         │
│  └─ setting: levenshtein_threshold   | % similitud (0-100)             │
│                                                                          │
│  Subcomando: status                                                     │
│  └─ Muestra: Estado, umbrales configurados, información                │
│                                                                          │
│  Subcomando: warnings                                                   │
│  ├─ usuario: @user   | Ver warnings acumulados                         │
│  └─ Info: Infracciones, timeout status                                 │
│                                                                          │
│  Subcomando: reset-warnings                                             │
│  ├─ usuario: @user   | Limpiar warnings                                │
│  └─ Resultado: Contador reiniciado a 0                                 │
│                                                                          │
│  📝 Ejemplo:                                                             │
│     /anti-spam config setting:levenshtein_threshold value:85           │
│     /anti-spam status                                                   │
│     /anti-spam warnings usuario:@spammer                               │
│     /anti-spam reset-warnings usuario:@user                            │
│                                                                          │

📋 FLUJO DE CONFIGURACIÓN RECOMENDADO

1. /setup-alerts alert_channel:#alertas log_channel:#logs
   └─ Configurar dónde se enviarán las alertas

2. /config
   └─ Ver valores iniciales

3. /anti-raid config setting:join_rate_limit value:10
   └─ Personalizar Anti-Raid

4. /anti-spam config setting:levenshtein_threshold value:85
   └─ Personalizar Anti-Spam

5. /anti-nuke config setting:channel_threshold value:3
   └─ Personalizar Anti-Nuke

6. /stats
   └─ Verificar que todo funciona
